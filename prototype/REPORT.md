# 明朝体ディテール生成プロトタイプ — 検証レポート

## 目的

骨格（中心線）＋端点タグから、明朝体ディテール（うろこ・打ち込み・はね・はらい・テーパー）をパラメータ駆動でアウトライン化し、アルゴリズム化がどこまで効くかをコードで検証する。

## 実装概要

| ファイル | 役割 |
|---|---|
| `geometry.py` | 3次ベジェ／折れ線サンプリング、可変幅オフセット、SVG path 化 |
| `params.py` | `classic` / `modern` の2パラメータセット |
| `strokes.py` | ストローク種別ごとのディテール生成 |
| `skeletons.py` | 「二」「十」「永」の骨格データ |
| `generate_mincho.py` | SVG 出力と簡易検証 |

方式: 中心線をサンプリング → 各点の法線方向に可変半幅でオフセット → 閉じポリゴン。端点ディテール（うろこ等）は別ポリゴンとして重ね描き。

## 実行結果

```
python3 generate_mincho.py
```

- 生成: 6 SVG（3字 × 2パラメータ）
- XML パース: 全ファイル成功
- `viewBox="0 0 1000 1000"`: 全ファイル一致
- パス閉じ（M 数 ≤ Z 数）: 全ファイル OK
- 塗り: `#000000`、`fill-rule="nonzero"`

## うまくアルゴリズム化できた部分

1. **横画の基本構造**  
   右上がり（約1.2–1.6°）、細い帯（≈42–45 u）、左打ち込み＋右うろこをタグとパラメータで切替可能。`classic` はうろこ大・凹み大、`modern` は小で、同一骨格からディテール差が出る。

2. **縦画の太さコントラスト**  
   横≈45 / 縦≈100 のコントラストがパラメータだけで再現できる。下端タグで「止め」「はね」を切替可能（「十」=止め、「永」=はね）。

3. **左はらいのテーパー**  
   中心線ベジェ＋幅プロファイル（根元→0）で、針状の先端まで機械的に生成できる。サンプリング＋オフセット方式との相性が良い。

4. **右はらいの膨らみプロファイル**  
   `right_hara_bulge_t` 付近で最大幅、先端で急減衰する関数で「途中で膨らんで鋭く抜ける」形は概ね再現できる。

5. **点（涙滴）**  
   短いベジェ＋sin 系プロファイルで涙滴形が得られる。パラメータ（長さ・幅）でサイズ調整可能。

6. **永字八法の網羅試験**  
   「永」1字で点・横・縦＋はね・策・長撇・短撇・捺を一通り通せた。ストローク種別カタログとしての骨格表現は有効。

## 破綻した／手作業が要ると分かった部分

1. **交差部（接合）の未処理（最大の穴）**  
   ストロークを独立ポリゴンとして重ねるだけなので、「十」「永」で横×縦の交差が「貫通」「隙間」「二重輪郭」になる。本格フォントにはブーリアン和、または接合部専用の接続ルール（角の整形・優先ストローク）が必須。

2. **端物と本体の接合品質**  
   うろこ／打ち込み／はねを別ポリゴンで食い込ませて見た目の隙間は減らせるが、単一輪郭への統合・共有エッジの整形は未実装。アウトラインフォント化にはマージとクリーンアップが要る。

3. **はらい曲線の「書の質」**  
   幅プロファイルは効くが、中心線ベジェ自体の曲率が骨格座標任せ。名筆に近い捺・撇にするには、曲率拘束・圧力曲線・先端角度の別モデル、または調整済みテンプレート曲線が必要。オフセットだけでは「美しいはらい」は保証されない。

4. **オフセットの幾何欠陥**  
   急カーブ・幅急変で自己交差や折り返しが起きうる。今回の字形では致命傷は少ないが、一般字形では miter 制限・曲率適応サンプリング・自己交差除去が要る。

5. **うろこ形状の様式差**  
   高さ・幅・凹みの3パラメータでクラシック／モダンの差は出るが、実在書体のうろこは複数曲線の組み合わせ。三角形近似では「らしい」止まりで、製品品質には輪郭テンプレ or 学習ベースが必要。

6. **骨格設計自体の手作業**  
   「永」の座標・制御点は手置き。アルゴリズムはディテール生成であり、骨格のバランス（字面・重心・ストローク配置）は別問題として残る。

7. **黒い重なりの見た目依存**  
   現状は塗り重ねで成立している。制作パイプライン（TTF/OTF、ヒント、バリアブル）に載せるには、単一単純閉経路（または正しいコンポーネント構造）への変換が別工程になる。

## 結論

**「ディテール生成のアルゴリズム化」はプロトタイプとして機能する。**  
同一骨格からパラメータ差（classic/modern）でうろこ・打ち込み・はね・はらい幅が変わり、SVG として安定出力できた。

一方、**製品レベルの明朝体にはならない。**  
特に交差接合・単一輪郭化・はらいの曲線美は、オフセット＋端点タグだけでは足りず、接合ソルバと曲線編集（またはテンプレート）が次の壁になる。

次の実験として有効そうなもの:

1. 交差部のブーリアン和（または優先ルール付き接合）
2. 端物を本体パスに接続した単一輪郭化
3. はらい用の曲率／幅の正規化テンプレート
