# 残り10字を Glyphs で描く

**済（G1 字形＋G2 字間）**。正本: `fonts_out/MyMincho.ufo`。帯外だった字は `FREEZE_g2.json`。え・おは G1 のまま帯内。

対象: **う・え・お・か・け・こ・す・せ・そ・て**

正本はまだ空。各字は作業 UFO `fonts_out/manual_kana/{字}.ufo` に描く。
ガイド PNG は UFO 内と `~/Desktop/MyMincho手書き/{字}.png`。

触らない: 核心20字＋の（出荷済み）。次の手描きは `DRAW_UI.md`。

## 開く（1字ずつ）

1. Glyphs で `fonts_out/manual_kana/う.ufo` を開く（次の字も同じ）
2. `uni3046`（う）をダブルクリック
3. **表示 → 画像を表示** をオン
4. 灰色の仮表示は無視。点を置くと消える

見えなければデスクトップの `{字}.png` をキャンバスへドラッグして Lock。

## 共通ルール

- 閉じた輪郭（ソーセージ）を画ごとに1つ。**合体しない**
- 重なってよい。穴パスは作らない
- **Filter → Remove Overlap** 禁止
- 交差が白い＝逆巻き → そのパスだけ **Reverse Selected Contours**
- なぞらない。位置を見るだけ
- 幅 1000。左ガイド LSB 126、右は RSB 126 の目安（x=874）
- **File → Save**。終わったらチャットで「う置いた」などと送る

参照4書体は union 済みなので輪郭数が少ない。描くときは分けたまま。

## 塗り（目安）

| 字 | グリフ | 塗り | 中身 |
|---|---|---|---|
| う | `uni3046` | 2 | 上の点。下の大きな弧（開いた C。ドーナツにしない） |
| え | `uni3048` | 3 | 上の短い横。中の横。下の払い |
| お | `uni304A` | 3 | 横。縦。回り（あと同じく開いた C。十のそばから出す） |
| か | `uni304B` | 3 | 左の縦。右の曲がり。右上の点 |
| け | `uni3051` | 3 | 左の縦。横。右の縦 |
| こ | `uni3053` | 2 | 上の横。下の横 |
| す | `uni3059` | 2 | 横。縦＋結び＋払い（輪は帯。穴にしない。ラテン s にしない） |
| せ | `uni305B` | 3 | 横。左の縦。右の曲がり |
| そ | `uni305D` | 2 | 上の短い入り。下へ続く払い（1本にまとめてもよい） |
| て | `uni3066` | 2 | 上の横。下の払い |

おすすめ順: **こ → て → う → け → か → え → せ → そ → す → お**（簡単なものから）。

## 「す」だけ詳しく

ラテンの **s**（一本のカーブ）にしない。あで穴を作ってラテン a になったのと同じ失敗を、輪でやらない。

1. **横**  
   上の一画だけ。左に打ち込み、右で止める。縦を横切る。縦と合体しない。
2. **縦＋結び＋払い**  
   横の上から下ろす。横の下で左へ回り、また縦に戻って交差する。交差したあと左下へ払う。  
   輪の中の白は、帯が囲んでいる紙。**外側の大きな楕円＋逆巻きの穴は作らない。**

終わったらパスは **2つ**。両方黒（Fill）。輪の中だけ白い。輪の中まで黒ならドーナツ塗りになっている。

正本 `MyMincho.ufo` は開かない。描くのは作業 UFO だけ。受け入れは `scripts/receive_manual.py`。

## 描いたあと（こちらでやる）

```bash
engine/.venv/bin/python scripts/receive_manual.py う
```
