# 「あ」を Glyphs で3塗りする

正本: `fonts_out/MyMincho.ufo` のグリフ `uni3042`。
背景の薄い「あ」は参照ラスタのガイド。**なぞらない。** 形の位置を見るだけ。

## 開く

1. Glyphs 3 でこの UFO を開く（フォント一覧が出る）
2. `uni3042`（あ）をダブルクリックして編集画面へ
空のときに出る灰色の「あ」はお手本ではない。Glyphs が「これはあですよ」と出す仮表示で、点を置くと消える。

本物のガイドはこう載せる。

1. **グリフ → 画像を追加…**
2. `proofs/review/a/glyphs_bg/a_guide_ipaex.png` を選ぶ
3. **表示 → 画像を表示** にチェックが付いていることを確認
4. 画像を右クリックして **Lock**

`Cmd-B`（背景レイヤーを編集）は別物。画面が暗くなったらもう一度 `Cmd-B` で戻る。

## 道具

| キー | 道具 | 用途 |
|---|---|---|
| `P` | Draw（ペン） | 輪郭を置く |
| `V` | Select（選択） | 点を動かす |
| スペース | 手のひら | キャンバスを掴む |
| `Cmd +` / `Cmd -` | ズーム | |

塗りつぶしの確認は **View → Fill**。編集中の字は、Text / Hand / Zoom に切り替えると塗りが見える。

## 1本の塗り（これを3回やる）

ペン（`P`）で **閉じた輪郭** を1つ作る。線ではなく、中が黒くなる輪っか。

1. キャンバスをクリックして点を置く。クリックだけなら直線、ドラッグすると曲線
2. 明朝の画は「細長いソーセージ」だと思う。画の外側を一周する
3. 最初の点をもう一度クリックして閉じる。開いたままは書き出しで消える
4. `V` に戻して点を直し、背景のその画にだいたい重なるようにする

最初は直線の多角形でよい。あとから `V` で辺を Option-クリックするとハンドル（曲線）が付く。

## 3本の中身

同じことを3回。**合体しない。** 重なってよい。

1. **横**  
   上の短い一画。左に打ち込み、縦を横切る。今のエンジンより長くてよい。
2. **縦**  
   横の上から下ろす。回りの内側を通り、結びのあたりで止まる。
3. **回り**  
   **十（横と縦の交差）のすぐそばから**左上へ出て、左を大きく回り、下をくぐり、右下へ抜ける。閉じたドーナツにしない。開いた C の帯。

終わったらパスは **3つ**。4つ目のゴミは消す。

## 向き（白抜きにしない）

1. **Path → Correct Path Direction**（`Cmd-Shift-R`）
2. Fill で見る。3本とも黒ならよい
3. どれかが白（穴）になったら、そのパスだけ選んで右クリック **Reverse Selected Contours**

穴用の逆巻きパスは作らない。カウンターの白は、回りの C が開いているから見える。

## やってはいけない

- **Filter → Remove Overlap**（`Cmd-Shift-O`）— 3塗りが1輪郭になる
- 書き出しダイアログの **Remove Overlap** にチェック
- 参照フォントをマスターとして開いてパスをコピーする
- 背景をペンでなぞる（トレース）

## 字間

左のガイドラインが LSB 126。右が「RSB も 126 なら」の目安（x=874）。  
実際の RSB は 98–138 に入ればよい。幅は 1000 のまま。

## 保存

**File → Save**（UFO に上書き）。終わったらチャットで「置いた」と送る。
