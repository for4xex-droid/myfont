# /expert-review - 5人の専門家パネルによる多角的レビュー 🎓

このワークフローは、実装されたコードやアーキテクチャ設計を、異なる専門領域を持つ5人のエキスパートの視点からシミュレーションしてレビューします。単一の視点では見落としがちなリスクや改善点を明らかにするためのワークフローです。

## 対象
- 新機能実装の PR やマージ前のレビュー
- アーキテクチャの変更やセキュリティ機構の導入後
- 重要な設計判断 (ADR) の作成時

## 実行手順

### 1. レビュー対象の特定
ユーザーから指定されたコード、実装計画、または PR の差分をターゲットとします。
もし対象が明確でない場合は、最近変更されたコードを対象と見做します。

### 2. コンテキスト展開 (Context Gathering)
対象コードに関連するドキュメント（ADR、CHANGELOG、`grep_search` による物理波及スキャン結果、`RIPPLE_MAP.md` による意味波及など）も必要に応じて読み込み、実装に至る背景を把握します。

### 3. 5-Expert Panel シミュレーション実行
以下の5つのペルソナ（専門家）になりきり、対象についてそれぞれの専門領域から「評価」「指摘事項」「深刻度」を提示します。

1. **Rust セキュリティアーキテクト（言語/フレームワーク専門）**
   - 焦点: Rust の型システム、所有権、非同期実行の安全性、フレームワーク（Axum/Tower等）のイディオムやベストプラクティスが守られているか。

2. **Web アプリケーションセキュリティエンジニア (OWASP専門)**
   - 焦点: アクセス制御、認証/認可（Broken Access Control）、タイミング攻撃耐性、XSS/CSRF などの一般的な Web 脆弱性。

3. **Rust コンパイラ/型システム研究者**
   - 焦点: 型システムを通じたビジネスロジックの制約（Typestate Pattern等）が十分に活用されているか、コンパイル時安全性の限界。

4. **DevOps/CI/CD エンジニア**
   - 焦点: 自動化の堅牢性、パイプラインの偽陽性・偽陰性、しきい値の妥当性、パフォーマンスへの影響、運用時のデバッグのしやすさ。

5. **プロダクトセキュリティ責任者 (CISO観点)**
   - 焦点: ビジネスリスク、単一障害点 (SPOF)、フェーズ移行に伴う過渡的な脆弱性、セキュリティの自動化レベルに対する投資対効果。

### 4. 総合スコアカードの作成
各専門家の評価を 5点満点 (⭐) で独自に採点し、サマリー表を作成します。

### 5. アクションアイテムの分類
指摘された改善点を以下の2つに分けて提示します。
- **Quick Wins (即座に対応すべき改善点)**: 容易に修正可能で効果が高いもの。
- **中長期的な改善点 (Future Considerations)**: フェーズを跨ぐ、または根本的なアーキテクチャ変更を伴うもの（将来の ADR 候補など）。

---

## 期待される出力フォーマット

以下の2つの形式でアーティファクトを出力します。

#### 1. Markdown サマリー
各専門家の主要な所見を簡潔に記述。

#### 2. 専門家パネル HTML レポート
`expert_review_report.html` という名前で、以下の要素を含む HTML を生成してください。
- **専門家タブ**: 5人の専門家の意見をタブ切り替えで閲覧できる UI。
- **ビジュアル・スコアカード**: 平均点と各専門家のスコアをプログレスバーやスターで視覚化。
- **ペルソナ・アバター**: 各専門家の個性に合わせた配色やアイコン（SVG）の配置。
- **クイックアクション・リスト**: 即座に対応すべき事項をチェックリスト形式で強調表示。
- **Interactive Feedback (JS Bridge)**: アクションアイテムの下に、修正作業をエージェントに自動実行させるためのボタンを配置してください。以下のHTML属性を使用して、Management Console のチャットへ直接プロンプトを送信できます：
  `<button class="aiome-feedback-btn" data-aiome-feedback="実装された Quick Wins の修正を適用し、再度テストを実行してください。" data-autosend="true">Auto-Fix Quick Wins</button>`

## 🧠 エージェントへの絶対指示 (Agent Directive)
このコマンドを呼び出された場合、対象コードを深く読み込み、各ペルソナのロールプレイを妥協なく行ってください。「ただ褒めるだけ」の忖度したレビューは不要です。各専門家は非常に高い視座で、プロダクションレベルのプロフェッショナルとして厳密で耳の痛い指摘を行ってください。
