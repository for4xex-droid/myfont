## 1. 商標「Irodori」

### 調べ方

- EUIPO の TMview API で `irodori`・`いろどり`・`イロドリ` を照会した（日本・国際登録・EU・米国）。`irodori` は167件すべて、かな表記は2181件中の上位300件を見た
- 指定商品と類似群コードは patent-i.com の登録原本の写しで確かめた
- J-PlatPat は画面操作が前提のため直接は照会していない。最終確認は J-PlatPat「商標検索」で称呼「イロドリ」、類似群 `11C01`・`42X11`・`26D01`・`26A01` を指定して行う

### フォントの区分

日本の審査基準では、ダウンロード販売のフォントは第9類「電子計算機用プログラム」と同じ類似群 `11C01` に入る（モリサワ登録第5321189号の指定商品「フォント用コンピュータプログラム」など）。第42類「電子計算機用プログラムの提供」（`42X11`）は `11C01` と**備考類似**で、異議申立や無効審判では類似と判断される。第16類（`25B01` 文房具・`26A01` 印刷物）は紙の活字や印刷物の区分で、デジタルフォントの本体ではない。

### 海外

- 米国 第6931777号・EU 第018936289号「IRODORI」（Irodori, Inc.）: 9類・41類。指定は同人誌などの電子書籍で、フォントとは別の商品。ただし9類で同じ語のため、海外で出願するなら要確認

### 判断

- 「Irodori ＋ 様式名」を**フォント名として使うのは危険が高い**。様式名（Modern・Classic・Chic・Pop）は説明語で、要部は「Irodori」と見られる。国際交流基金の `11C01` 登録と類似し、登録は拒絶され（商標法4条1項11号）、使用は侵害を主張されうる（同法25条・37条）
- 国際交流基金は公的機関で、教科書『いろどり』は広く知られている。出所の混同の主張も受けやすい
- 取りうる道: (a) 名前を替える、(b) 「Irodori」に造語を足して一語にし、全体で新しい称呼にする、(c) 弁理士に類否の意見を求めてから出願する。2026-09-30 に (a) を選んだ

### 判断

- 登記上の英文名は**存在しない**。登記された商号はカタカナだけで、「Motivation Studio LLC」は訳語になる。訳語を著作権表記に使うことは妨げられない
- 特定商取引法の表記には、**登記上の商号（日本語）**を書く。BOOTH のショップでも「モチベーションスタジオ合同会社」とする。英文名を特定商取引法の表記の販売業者名に使ってはならない
- 表記の一致を保つ案（未決定）: 英語の name ID 0 は今の英字だけの表記のままにする。日本語の name レコード（Windows、言語 ID 0x0411）を足し、`Copyright 2026 モチベーションスタジオ合同会社. All rights reserved.` を入れる。EULA の冒頭には「Motivation Studio LLC（モチベーションスタジオ合同会社）」と両方を書き、同じ法人であることを示す
- 自社サイトの特定商取引法の表記は、カウンセリングの予約を前提にした内容（キャンセル料の段階など）になっている。フォントのダウンロード販売には、別の表記（引渡時期、動作環境、返品特約）が要る。§3 の「特定商取引法」を参照

## 3. EULA の法的な論点

| 論点 | 要点 | EULA への反映 |
|---|---|---|
| 消費者契約法 8条1項・3項（令和4年改正、2023-06-01 施行） | 故意・重過失の責任を一部でも免じる条項は無効。軽過失の一部免除（上限額など）は、**軽過失にだけ適用されると条項で明示**しないと無効。「法律上許される限り」などの留保（サルベージ条項）は認められない | 第9条を「権利者の故意または重大な過失による場合を除き」と明示する形にした |
| 消費者契約法 10条 | 消費者の利益を一方的に害する条項は無効 | 解除の効果を「解除前の成果物は公開を続けてよい」と限った（既存の案のまま） |
| 民法 548条の2〜4（定型約款） | 表示して合意すれば組み入れられる。変更は、相手の一般の利益に合うか、合理的で変更の規定があるとき、効力発生時期と内容をネットで周知すれば一方的にできる | 第10条の2（本契約の変更）を足した。版付き URL は、旧版の条件を後から読めるようにする意味でも有効 |
| 特定商取引法 11条・15条の3（返品特約） | 通信販売は返品特約を広告に表示しないと、引渡しから8日以内の解除を受ける。デジタル商品でも特約の表示は省けない | 第13条（返品）を足した。同じ文を BOOTH の特定商取引法の表記にも書く |
| 書体と著作権 | 日本では、書体（字形）は原則として著作物にならない（最判平成12年9月7日「ゴナ」事件）。フォントファイルはプログラムとして著作物になりうる。EULA の保護の中心は契約とファイルの複製にある | 第7条の「権利の帰属」は、フォントファイル（ソフトウェア）を主に書いた |
| 著作権法 30条の4（情報解析） | 著作物を AI の学習に使うことは、原則として権利者の許諾なくできる。ただし契約で禁じれば、**契約した相手**は拘束される。契約していない第三者は拘束できない | 第5条3の AI 学習禁止は契約上の義務として残す。第三者に及ぶとは書かない |
| 合意管轄 | 自社の利用規約（第10条）は「当社の本店所在地を管轄する裁判所を第一審の専属的合意管轄裁判所」としている。本店は京都市北区のため京都地方裁判所（簡易裁判所の事物管轄に当たる額は京都簡易裁判所）。消費者の遠方の管轄を強いる条項は、消費者契約法10条で争われる余地がある | 第12条を自社の利用規約にそろえた。専門家の確認項目に入れる |
| BOOTH の規約 | BOOTH は場の提供者で、特定商取引法の表示義務はショップ（販売業者）が負う。請求があれば遅滞なく開示する体制を取るなら、住所・電話の表示を省ける | 法人のため登記上の商号をそのまま表示する |

**専門家に確認すること**: 第9条の上限額の書き方、第12条の専属的合意管轄を消費者に向けて使えるか、第10条の2 の変更条項が定型約款の要件を満たすか、第5条3の AI 学習禁止の書き方。

## 4. ベンダー ID `MTVS`

- 2026-09-30 に Microsoft Learn「Registered font vendors」を確かめた。`MTVS` は**未登録**
- 申請は、`mstwsite@microsoft.com` へのメールで行う。必須は Vendor ID と Foundry Name。任意でメールアドレスと Web サイト
- エージェントはメールを送れない。下の文面を、会社のアドレスから送る

```text
To: mstwsite@microsoft.com
Subject: Vendor ID registration request: MTVS

Hello,

We would like to register the following font vendor ID.

Vendor ID: MTVS
Foundry Name: Motivation Studio LLC
Email: info@motivationstudio.net
Website: https://motista.info/

Motivation Studio LLC (モチベーションスタジオ合同会社) is a company in Kyoto, Japan.
We plan to release the Latin display families under this ID.

Thank you,
［送信者名のローマ字表記］
Motivation Studio LLC
```

- 送信者名のローマ字表記は、本人が書く
- 一覧への掲載には時間がかかる。掲載前に他社が同じ ID を取った場合は、出荷前に ID を替える
- 文面の「Latin display families」には、ファミリー名を書いていない。名前が決まるまで書かない
