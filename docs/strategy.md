# MyMincho 事業戦略（リリース＆マネタイズ）v1

2026-08-09 策定。日本語フォント市場レポート（世界市場 CAGR ≈4%、国内寡占、LETS ゲーム組込終了→Monotype 約53倍高騰、法人化ペナルティ、生成AI知財リスク）と、本プロダクトの実態（クリーンルーム設計・`product_r1` 凍結済み・仮名未着手・小規模リソース）に基づく。Grok 4.5 レッドチーム独立分析を統合済み。

## 1. ポジショニング（ワンライナー）

大手が捨てた「インディー／同人のゲーム・アプリ組込」を、**透明ライセンス・買い切り・来歴クリーン**で取りに行く。造形の美しさや字数で正面勝負せず、**創作者をロックインしない**ことを製品価値にする。

3本柱:
1. **透明ライセンス明朝** — 個人・同人向け低価格買い切り（無料は組見本とデモ字のみ。全面無料は値崩れ）。アイコンで可否を示す明快な EULA
2. **買い切り＋メンテナンスライセンス** — 運営型ゲーム向けタイトル単位買い切り。解約後もバグ/OS対応の再コンパイルのみ許可する保守条項で「資産寿命の断絶」を解消
3. **セミカスタム生成（受託→型化→SaaS の順）** — パラメトリックエンジンの強み。品質実証（受託10件の満足）前に SaaS 化しない

## 2. リリースフェーズ

| 版 | 出荷物 | 字種 | ライセンス | 目安 |
|---|---|---|---|---|
| α（限定） | 組見本PDF＋限定OTF（仮名一式＋手設計核漢字50〜100＋英数約物） | 〜約300字 | 無料デモのみ・商用保証なし | t0=盲検合格日。外部盲検（UI/HUD 2面）で仮名の顔を確定 |
| β（公開検証） | Regular 1ウェイト・教育漢字はパイプ済みのうち品位到達分（頻出上位N≒200目安）＋既知問題リスト | 段階拡充 | L1買い切り販売開始（BOOTH） | 「常用完備」「教育完備」とは宣言しない。拡充は無償アップデート |
| v1.0（初回商用） | 常用フル＋頻出300字手修正＋第2ウェイト | 〜2,500字 | 組込L2・法人L3–L4・保守本格化 | 12–24ヶ月 |
| v2以降 | 縦書き・ウェイトファミリー・セミカスタム | パラメトリック展開 | 受託＋将来SaaS | 24ヶ月+。品質実証が先 |

鉄則: **仮名 → 組見本で「顔」確立 → 教育漢字 → 常用残り**。漢字エンジン先行公開は「読めない明朝」としてブランドを焼く。

## 3. マネタイズ階層

| 層 | 内容 | 価格帯目安 |
|---|---|---|
| L0 無料デモ | 数十字サンプル・組見本PDF | ¥0（認知のみ） |
| L1 個人・同人 | デスクトップ＋動画/同人誌配信 | ¥3,000〜8,000 買い切り |
| L2 ゲーム組込 | バイナリ同梱可・ユーザー数上限なし・法人化しても継続可 | ¥15,000〜40,000 買い切り |
| 保守ライセンス | 失効後もバグ/OS対応の再コンパイルのみ許可 | 買い切り額の15〜25%/年 |
| L3–L4 法人 | 席数/サイト＋Web（PV上限付き） | ¥5万〜60万 買い切り＋年メンテ |
| L5 セミカスタム | パラメータを振った専用面（受託） | ¥30万〜150万/件 |
| L6 フルカスタム | 仮名再設計＋例外字＋ガイドライン | ¥200万〜800万（年間上限2件） |

- 収益連動ロイヤリティは初期は採らない（監査コスト過大）。「売上閾値超過で上位層へ任意アップグレード」条項のみ
- チャネル: BOOTH（主）→ 自社サイト（信頼の正本）。GitHub はエンジン/計測の OSS 検討可、**製品 OTF の全面無料配布はしない**
- **販売オペを技術より先に固める**: 特商法表記・返金ポリシー・税込価格・BOOTH手数料・インボイス方針を1枚化（PLAN §7.1 S0）。β販売開始の必須条件
- ブランド確定前に家族名の商標調査と GlyphWiki データ利用条件の販売時再確認を済ませる（PLAN §7.1 S2a）
- AI 機能は販促でなく**内部 QC に限定**（欠字検知・品質スコアリング・受託時のパラメータ探索）

## 4. 差別化資産

- **来歴クリーン**: 参照フォント非トレース・GPL非リンク・KanjiVG形状非混入・KAGEデータのみ利用を SHA256＋パイプラインIDで証明可能 → 購入者向け「設計来歴カード」として商品化
- **ライセンス透明性**: アイコンベース可否表・エンジン名明記（Unity/Godot/Unreal）・学習データ投入禁止の明文化
- **パラメトリック展開性**: ウェイト・セミカスタムが構造的に可能（既製フォントに対する将来性）

## 5. 失敗シナリオ（レッドチーム上位3）

1. **漢字デモで売る** — 仮名後回しで「エンジンの習作」認定 → 仮名完成を唯一の Go/No-Go ゲートにする
2. **品質ゲート前に約束を売り切る** — 常用完備・組込無制限を初手で約束し返金と信用負債 → 段階出荷・過大宣言禁止
3. **LETS 需要の過大評価と価格競争** — ダイナコム/イワタ/フリーに潰される → 差別化はライセンス単純さ・来歴・保守保証・作者との距離

## 6. KPI（順序厳守）

1. **最初の唯一の KPI**: 仮名組見本の外部盲検合格。**主面は短文UI／ゲームHUD風**（事業ポジションに一致させる。文芸本文は参考観測）。評価者3名中ゲーム/同人制作者≥2、合否は **UI≥2/3 かつ HUD≥2/3**。売上・字数消化率はこの後
2. 1年: 有料販売件数・組込ライセンス比率・返金/品質苦情率 5%未満・手修正残件数
3. 3年: メンテ収入が新規販売の20〜40%・法人比率・受託粗利

実装への落とし込みは `PLAN.md` §7（事業整合ロードマップ）を参照。
