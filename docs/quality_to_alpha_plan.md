## 0. いまの位置

- 出荷正本 `fonts_out/MyMincho.ufo` にひらがな37字（核心20＋の＋UI16）が手描きで入っている。字間は LSB126 / RSB118 帯。コンパイルは `scripts/compile_manual_otf.py`（`remove_overlaps=False` の重ね塗り）
- 手描き37字は DNA A で IPAex 骨格から離した（P-D1 済。vs IPAex 平均 0.649）。黄金 `kana_g3_blind_d1`
- P1 外部盲検（`proofs/blind/RESULT_p1.txt`）: UI 3/3・HUD 3/3。評価者3名ともゲーム属性。**3名とも「B（自作）が若干荒い」**
- 合否は「使えるか」だけなので、**使えるが粗い**が残った。これは個別の失敗字ではなくセットの品位問題
- 仮名の顔はエンジンが負け、正本は方式Aに切替済み。エンジン YAML は研究・比較用として残す
- `data/glyphset_alpha.txt` は373字。本盲検文面 `ui.txt` / `hud.txt` はいま欠字だらけ

**一本の推奨**: 字数拡張より先に「荒い」を測って潰す。荒い未解消のまま増やすと粗さを量産する（掟20の精神）。

## 1. 「荒い」の実体

正本37字の観測（監査時点）:

| 観測 | 意味 |
|---|---|
| ゴミ輪郭（面積&lt;80）は0 | 今の正本は綺麗。事故は Glyphs が正本を保存するたびに起き、git で戻している |
| 平均点数 117.5（あ189 / ぼ185 / た166） | エンジン `cubic_fit` の目安は輪郭あたり ≤40–48。手描きはすでに cubic だが節点が多すぎて安フォント感が出やすい |
| 字間はほぼ帯内 | 歩行の主因ではない |
| overlay（重ね塗り） | 接合部が二重インク。UI サイズでジャギーに見えやすい |
| `fontinfo` に copyright / ライセンス / fsType なし | `ship_gate` の `name_table` は今落とせる |

本命は上から費用対効果が高い3層:

1. セットの太さ・黒み・字面が揃っていない（測れる。資産がある）
2. 節点過多とハンドルの揺れ（あ・そ・の・るなど。部分的に機械で減らせる）
3. 重ね塗りの接合ギラ（union は顔を溶かすので最初の手ではない）

**最初にやらない**: 37字全部に `cubic_fit`、全字 union、エンジンで描き直し。

## 2. 品位（Q）

- **目的**: 「荒い」を感想から、字ごと・指標ごとの差分に落とす
- **作業**:

- **依存**: なし

- **実装**: `scripts/refit_manual_kana.py`（既定は dry-run。書くとき `--apply`。し・く・っは拒否）
