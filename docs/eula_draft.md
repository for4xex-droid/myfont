## 4. ゲーム・アプリへの組み込み

1. 成果物の一部として、本フォントのファイルを同梱してよい
2. 同梱したフォントを、成果物の利用者が単体のフォントとして取り出して使えるようにしてはならない（暗号化やアーカイブへの格納など、通常の手段でよい）
3. 成果物の販売本数・利用者数に上限はない
4. 利用者が個人から法人になっても、許諾は続く

## 5. 禁止事項

1. 本フォント、またはその改変物を、フォントとして第三者へ配布・販売・貸与すること

3. 本フォントを AI・機械学習の学習、評価、または調整のデータとして使うこと
4. 本フォントの名前「Irodori」を、別のフォントの名前として使うこと
