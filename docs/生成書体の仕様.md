# 生成書体の仕様

- 状態: 正本
- 日付: 2026-09-24
- 最終更新: 2026-09-29
- 対象: このリポジトリのフォントジェネレータ出力を受け取る開発

開発に着手する前に、このファイルを開いて読む。要約や記憶で代用しない。

## 1. 方針の変更

日本語フォントの作成は休止する。漢字・仮名を含む明朝体の新規グリフ、骨格、盲検、品位作業、常用漢字の量産には着手しない。

以後の制作はアルファベットのフォントへピボットする。現行の作業対象はアルファベット書体だけとする。既存の日本語資産はリポジトリに残すが、現行の制作対象ではない。

## 2. 先方が受け取る出力

フォントジェネレータの出力について、先方は次を受け取る。値が「未決定」の項目は、決定してこの節へ書くまで、推測で実装や引き渡し物に埋め込まない。

### ファイル形式

OTF か TTF か: **両方を渡す**（2026-09-29 決定）

同じ書体ごとに OTF と TTF を1本ずつ渡す。

### 収録する字の範囲

最低限、次を収録する。これを欠く出力は受け取らない。

- 大文字 A〜Z
- 数字 0〜9
- スラッシュ `/`
- 空白 U+0020
- ノーブレークスペース U+00A0（空白と同じ字幅）

空白の2字は 2026-09-29 に追加を決定した。

小文字、約物、日本語は収録しない（2026-09-29 決定）。足すときは、この節に収録一覧を書き足す。

### 太さの数

**1**（2026-09-29 決定）

各様式を1ウェイトで作る。太さは様式ごとに、その様式らしい値にする。

### 等幅かどうか

**プロポーショナル**（2026-09-29 決定）

### 命名の規則

決定済み（2026-09-29）:

- 4様式（モダン・クラシック・シック・ポップ）は、それぞれ別のファミリーにする
- スタイル名: `Regular`
- ファイル名の付け方: `<ファミリー名>-Regular.otf` と `<ファミリー名>-Regular.ttf`。ファミリー名の空白は取り除く
- ファミリー名:

| 様式 | ファミリー名 | ファイル名 |
|---|---|---|
| モダン | Irodori Modern | `IrodoriModern-Regular.otf` / `.ttf` |
| クラシック | Irodori Classic | `IrodoriClassic-Regular.otf` / `.ttf` |
| シック | Irodori Chic | `IrodoriChic-Regular.otf` / `.ttf` |
| ポップ | Irodori Pop | `IrodoriPop-Regular.otf` / `.ttf` |

**未決定**:

- 商標の確認結果（J-PlatPat で「Irodori」を9類・16類に照会する）。確認が済むまで、上のファミリー名で先方へ渡さない

### ライセンス

決定済み（2026-09-29）:

- 独自ライセンス（EULA）。SIL OFL などのオープンライセンスにはしない
- 埋め込み許可（OS/2 fsType）: Installable（0）
- 権利者名: Motivation Studio LLC。著作権表記は `Copyright 2026 Motivation Studio LLC. All rights reserved.`
- EULA: フォント内部には要約と URL だけを入れる。本文は自社サイトに版付きの URL で置く。下書きは `docs/eula_draft.md`
- ベンダー ID（OS/2 achVendID）: `MTVS`。Microsoft のベンダー ID 一覧へ登録を申請する
- バージョン表記: `Version 1.000` の形式。head の fontRevision と一致させる。修正で 1.001、字や機能の追加で 1.100 と上げる。出荷前の内部ビルドは 0.xxx

**未決定**:

- 権利者名の登記上の英文表記の確認（上の表記と違えば直す）
- EULA 本文の確定（専門家の確認を含む）と、置き場所の URL

## 3. 読み方

このファイルが生成書体の正本である。実装、レビュー、引き渡しの前に開く。未決定の項目が残っているあいだは、その項目を決めた体で先方へ渡さない。
