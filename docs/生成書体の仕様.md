# 生成書体の仕様

- 状態: 正本
- 日付: 2026-09-24
- 最終更新: 2026-09-30
- 対象: このリポジトリのフォントジェネレータ出力を受け取る開発

開発に着手する前に、このファイルを開いて読む。要約や記憶で代用しない。

## 1. 方針の変更

日本語フォントの作成は休止する。漢字・仮名を含む明朝体の新規グリフ、骨格、盲検、品位作業、常用漢字の量産には着手しない。

以後の制作はアルファベットのフォントへピボットする。現行の作業対象はアルファベット書体だけとする。既存の日本語資産はリポジトリに残すが、現行の制作対象ではない。

## 2. 先方が受け取る出力

フォントジェネレータの出力について、先方は次を受け取る。値が「未決定」の項目は、決定してこの節へ書くまで、推測で実装や引き渡し物に埋め込まない。

### ファイル形式

OTF か TTF か: **両方を渡す**（2026-09-29 決定）

同じ書体ごとに OTF と TTF を1本ずつ渡す。

### 収録する字の範囲

最低限、次を収録する。これを欠く出力は受け取らない。

- 大文字 A〜Z
- 数字 0〜9
- スラッシュ `/`
- 空白 U+0020
- ノーブレークスペース U+00A0（空白と同じ字幅）

空白の2字は 2026-09-29 に追加を決定した。

小文字、約物、日本語は収録しない（2026-09-29 決定）。足すときは、この節に収録一覧を書き足す。

### 太さの数

**1**（2026-09-29 決定）

各様式を1ウェイトで作る。太さは様式ごとに、その様式らしい値にする。

### 等幅かどうか

**プロポーショナル**（2026-09-29 決定）

### 命名の規則

決定済み（2026-09-29）:

- 4様式（モダン・クラシック・シック・ポップ）は、それぞれ別のファミリーにする
- スタイル名: `Regular`
- ファイル名の付け方: `<ファミリー名>-Regular.otf` と `<ファミリー名>-Regular.ttf`。ファミリー名の空白は取り除く
- ファミリー名:

| 様式 | ファミリー名 | ファイル名 |
|---|---|---|
| モダン | Someiro Modern | `SomeiroModern-Regular.otf` / `.ttf` |
| クラシック | Someiro Classic | `SomeiroClassic-Regular.otf` / `.ttf` |
| シック | Someiro Chic | `SomeiroChic-Regular.otf` / `.ttf` |
| ポップ | Someiro Pop | `SomeiroPop-Regular.otf` / `.ttf` |

- 名前の由来は「染め色」。最初の案「Irodori」は、国際交流基金が9類 `11C01`（フォントと同じ類似群）に登録している「ＩＲＯＤＯＲＩ Practice」などと衝突する危険が高く、2026-09-30 に替えた（`docs/legal_research.md` §1）

**未決定**:

- 出願前の商標調査の結果（J-PlatPat で称呼「ソメイロ」、類似群 `11C01`・`42X11`・`26D01`・`26A01` を照会し、弁理士の確認を受ける）。2026-09-30 の一次調査では、日本の9類・42類に先行はなかった。確認が済むまで、上のファミリー名で先方へ渡さない
- 商標を出願するか（出願するなら9類と42類）

## 3. 読み方

このファイルが生成書体の正本である。実装、レビュー、引き渡しの前に開く。未決定の項目が残っているあいだは、その項目を決めた体で先方へ渡さない。
