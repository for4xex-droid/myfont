## 2. 既存案のレビュー

出典は実装計画 §2.6・§2.7・§5、表示計画、ベクター品質計画。サブエージェント2本の監査（既存案の棚卸し、比較シートと実装の監査）を手元で確かめた。

採る:

- **丸い字を太くする補正**（§2.6）。§4 の再凍結にまとめる。モノライン（モダン・ポップ）は丸の太さを 1.5–2.5%。nib は碗の太い方向だけ。グループのスカラーで持ち、字ごとに書かない。クラシックの O の墨量が H の 0.90 という監査の値は、墨量で測り直して確かめた（§2.6 の「差 0%」は画の太さの比較で、墨量ではない）
- **ポップ B の曲率の跳び**（§2.7）。D・P・R が同じ碗の経路に乗る前に直す。外形は動かさず、穴の側だけ
- **クラシック TTF の G-TT**。B の 1.25 は局所の分割で 1.0 以内にする。設計の輪郭と分離は動かさない。O の 1.0004 は丸めの端なので同じ手当てで消える見込み
- **小さい穴の保護**（ベクター品質計画 Phase 0a の考え方）。包含が奇数で、カウンターの床以上の負輪郭だけ残す。A・4・R・8 の前に決める
- **G-O・G-SET・G-M**。2026-10-07 に `gate.py` へ繋いだ。パイロットに赤はない。31字を足したときに帯の外ならテストが落とす。帯の数値は凍結していない

改める:

- **字間は工程10まで待つ**（§7）→ 待たない。本調整（リズム・カーニング）は37字のあとでよいが、墨を基準にする土台は今直す。負の余白のまま31字を作ると、全字の送り幅を作り直すことになる
- **オーバーシュートを草案の帯（丸 1.5–2%、尖り 2–3%）へ戻す**→ 帯へ一律に戻さない。様式の太さで決める。ポップだけ上げる（太い丸ほど大きく要る）
- **サンセリフの O の上下を左右の 0.95 に**→ 幾何モダンの正円に合わない。採らない。丸を太くする補正で足りる
- **モダン B の `deepen_outer_waist`**→ 字別の特例をやめ、二階の碗の接合のフィレットで同じ見え方を出す
- **シック V の右脚を `thick` にする**（実装計画 §2.3 方針1、10/1）→ 細くする（§5）。ヘアラインにすると針になるという理由は正しいので、ヘアラインではなく中間の太さの役割を足す

見送る:

- クラシックの O を細くする（§5 で 0.97 のままに決定）
- ポップの跳ね（ベースラインのずれ、回転）。字間が壊れる
- 急曲率の追加サンプル。区間 96 で足りている

### 3.1 字間の土台

| 項目 | 内容 | 判定 |
|---|---|---|
| 墨を基準にする | 側面の係数を、骨格の箱ではなく墨の外側（bbox）に掛ける。送り幅 = 墨の幅 + 左右の側面 | 済。全字で左右の余白 ≥ 0。斜め < 丸 < 直線（§1） |
| HOH と OHO | 管理文字列の空き面積の比を記録する（帯はまだ凍結しない） | 済。比は 1.0（対が同じため）。下に面積 |

分離は動かない（形を測っていて、送り幅を測っていない）。輪郭は x の平行移動だけで、保存した形との差は 0.01 以内だった。動かした字のフィクスチャは、その移動分だけ x を足して更新した。

キャップハイトの帯で積んだ、字と字のあいだの白（`line_gap_area`）。HOH と OHO は同じ対なので比は 1。参考として、H と O のあいだ ÷ H と H のあいだ:

| 様式 | HOH の白 | H–O / H–H |
|---|---|---|
| モダン | 216000 | 1.38 |
| クラシック | 237000 | 1.17 |
| シック | 183000 | 1.05 |
| ポップ | 196000 | 1.53 |

帯にはしない。1 より大きいのは、丸の側面を直線より詰めても、O の脇がまだ H の脇より白い、という意味。

### 3.3 31字へ広げるときの規則（工程7の前に書く）

字を作る前に、骨格と様式に規則として書いておく。

- 股の細め: §5 の値（ポップ 0.85、モダン 0.90、クラシック 0.82、シック 1.0）。組見本の MNWK で確かめる
- セリフは同じテンプレートを全字で共有する。長さと厚さは様式の値だけから決める
- 横棒の高さ: H E F は §3.2 の様式の値。A の横棒は別の値（低く置く）として様式に持つ
- 細い斜画: シックの A の左、W の2本目と4本目、X の ／、Y の右は `slant_thin`。N と M の縦画はヘアライン（`thin`）のまま
- 頂点と股: A V W M N X Y の頂点は外縁で決め、細めは脚全体の一様な先細りで入れる。局所で太さを変えない（`docs/latin_v_plan.md` §3.1・§6）。`crotch_thin` も同じ作り方に替えてから M N W K を作る
- 開いた端: S C G は `beak`。J 2 3 5 6 9 の丸い端は `round_end`（シックは玉）
- 数字はライニング。0 と O、1 と I を見分けられる形にする。数字の幅は様式内でそろえる範囲を決める
- `/` は太さを斜画と同じにし、端は様式の端物に従う
- 様式ごとに、目で見て分かる特徴を3つ以上、骨格に書く（実装計画 §6.4）

## 4. 計画（分離を動かす段階）

§3 と組見本の確認が済んでから、次をまとめて一度に入れ、一度だけ再凍結する（§5 で決定）。

| 項目 | 内容 | 動く軸 | 分離への向き（§1 の試算） |
|---|---|---|---|
| 丸い字を太くする | モノラインは丸の太さを 1.5–2.5%。nib は碗の太い方向だけ | contrast（nib）、O 幅/高さ（わずか） | クラシックのコントラストが上がり、最近ペアは広がる |
| ポップのオーバーシュート | 丸を約 2.5% に上げる。頂点の丸の半径を幹より小さく | o_width_over_height | ほぼ動かない |
| シックの穴（§3.2 で動いた場合） | 楕円の穴でコントラストが動くなら、ここで入れる | contrast | 上がると最近ペアが縮む。シックのコントラストは 8.5 以下に収める |

手順:

1. 入れる前に、凍結値・最近ペア・閾値を記録する
