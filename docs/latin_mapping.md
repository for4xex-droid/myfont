# ラテン骨格の語彙

工程 2 の閉じた語彙。骨格 YAML は、ここにない値を書くとロードが失敗する。

## 節点

| 型 | 意味 |
|---|---|
| `smooth` | 接線が連続。Hobby 展開 |
| `corner` | 接線が不連続。ここで曲線を分ける |
| `line` | 隣の節点と直線で結ぶ。角度は付けられない |

接線を固定するときは、節点の4番目に角度（度。+x から反時計回り）を書く。`line` には付けない。

## 役割 `role`

`thick` / `thin` / `bar` / `arm` / `bowl` / `run` / `slant_thin`

## 端 `ends`

`foot` / `apex` / `none` / `open` / `round_end`

どのテンプレになるかは様式が決める。

## 側面 `sides`（Tracy の5段）

`straight` / `near_straight` / `round` / `diagonal` / `open`

左右は独立。グループ名には使わない。

## 接合 `joins.type`

`apex` / `apex_cut` / `stem_apex` / `T` / `L` / `crotch` / `bowl_join`

## グループ `groups`

`straight` / `round` / `diagonal` / `open` / `bar`

ペンと比だけを上書きする。側面の空き（`sidebearing`）は書けない。

## 構造 `structure`

`stem_pair` / `bowl` / `apex_diagonals` / `spine` / `branch` / `stem` / `diagonal`

## 様式名（`variants` のキー）

`modern` / `classic` / `chic` / `pop`

## 31字へ広げるとき

字を足す前の規則。未決定の数値は、作者が組見本で決めるまで骨格にも様式にも書かない。

### 横棒と腕

- `bar` の中心は骨格の y ではなく、様式の `metrics.bar_y`。H の横棒、E と F の中棒がこれ。
- `arm` は天か地の腕。骨格の y は外縁で、0 が地、1 が天。中心はペンの半幅だけ内側に寄り、外縁が基準線に乗る。`bar_y` へは動かさない。太さは `bar` と同じ（`bar_ratio`）。
- E の天と地、F の天、L の地、T の天は `arm`。E と F の中棒は `bar`。
- A の横棒は `bar` にしない。モダンでは中心をキャップの 0.22 に置く（2026-11-03 作者が組見本で決定）。ほかの様式は未決定。

### 側面

左右は独立に、Tracy の5段から選ぶ。

- I は `straight` / `straight`
- L は `straight` / `open`
- T は `open` / `open`
- E と F は `straight` / `open`

### 平らな字

先端（`apex`）も、接合していない碗も無い字は、オーバーシュートを付けない。天地はベースラインとキャップハイト。

### 曲線の字

- 接合していない碗は、丸い天地を様式の `overshoot.round` に合わせる。幹に接合した碗（B と D）は、天地を 0 とキャップハイトのままにする。
- `foot` の端は、その側を基準線に合わせ、オーバーシュートしない。U の幹の天、J の天がこれ。底の弧は丸のオーバーシュート。
- C の開いた端は `open`。中心線は O と同じ円（枠のあとでは同じ縦横比の楕円）の弧で、端から端まで曲がりの向きは一定。モダンでは弧の端を垂直に平切りする（向きは暫定）。開きの高さは暫定。
- J の丸い端は `round_end`。モダンでは平切り。底は基線の丸で、ディセンダーへ下ろすかは未決定。作者が組見本で決める。
- 側面: C は `round` / `open`。D は `straight` / `round`。J は `open` / `straight`。U は `straight` / `straight`。
- P と R は幹に接合した碗。下の入りは `bar_y`。天はキャップ。右の幅は B の上の碗に `upper_bowl` を掛けた位置（暫定）。側面は `straight` / `round`。
- R の脚は骨格の直線。碗の下の入りから基線へ下り、基線で平切りする。オーバーシュートも拍車も無い。脚の出は暫定。
- モダンの G はひげも縦も無い。下の弧を C と同じ円に沿って右側の横棒の高さまで巻き上げ、そこから内へ横棒を出す（2026-11-03 作者が組見本で決定）。横棒の高さと長さは暫定。ほかの様式の G は未決定。

### 構造

- `stem` は腕のない縦の幹。I がこれ。
- `branch` は幹に腕が付く字。L T E F がこれ。Y もこれ（斜画2本と縦の幹）。Z もこれで、斜画が幹の役をする。
- `diagonal` は幹も頂点もない斜画の字。交差も含む。X とスラッシュがこれ。
- Z は天と地の `arm` と、そのあいだの斜画。斜画の切り口は腕の外へ出さない。天地は平ら。
- X は2本の斜画が交差する。太さは mono の幹。端は平切りで天地に乗る。頂点の接合は使わない。
- Y は上の2本の斜画と、基線までの縦の幹。交点は縁の交わりで決め、局所では細めない。腕の中心線が会う高さは暫定（単位座標 0.50）。幹の天はその交点のすぐ下。

### 股の細め

最終値は未決定。作者が組見本の MNWK で決める。コードが使う暫定値は、ポップ 0.85、モダン 0.90、クラシック 0.82、シック 1.0。

股に入る画（接合の a 側）だけを細める。相手の幹は細めない。片側だけ細いときは、半幅を弧長に対して一次にする。hw(s) = hw0 × (1 − (1 − t) · s / L）。s = 0 が太い端で、股の端が細い端。端が `none` のとき、その端が細い。両端を細くする画（両端が `foot` の股、または両端が頂点）は先細りにしない。半幅は全長で hw0 × t の一定にする。中心線がまっすぐなら縁もまっすぐで、中央に折れは出ない。端の 22% だけを細くする作りは使わない。

### セリフ

セリフは同じテンプレを全字で共有する。長さと厚さは様式の値だけから決め、字ごとに書かない。モダンの端は平切りで、I L T E F にセリフは無い。

### 細い斜画

シックの A の左、W の2本目と4本目、X の ／、Y の右は `slant_thin`。N と M の縦画は `thin` のまま。I L T E F に斜画は無い。

### 頂点と股

A V W M N X Y の頂点は外縁で決める。細めは脚全体の一様な先細りで入れ、局所で太さを変えない。I L T E F に頂点と股は無い。

モダンの頂点は外縁の交点で、平切りは `apex_flat`、先細りは片側だけの `apex_taper`。谷は内縁の交点で、尖ったまま残す。はみ出すのは尖った頂点だけで、幅は `overshoot.apex`。M の天（幹の外縁と斜画の外縁）、N の左上と右下、W の中央もこれ。M の谷と W の下の2頂点は基線より下。M の左右の幹は垂直（開きは暫定）。W の外側の足はキャップに乗る。M と N の斜画は両端が頂点なので、縁は平行で太さは `crotch_thin` 倍の一定。K の腕と脚は股の細めで、幹の右縁の1点で会う（暫定）。X と Y は頂点の接合を使わない。

`stem_apex` は縦の幹（`a`）と斜画（`b`）が鋭い外頂点で会う接合。斜画は節点の位置から置き、外縁は頂点の高さで幹の外縁を通る。その線より外を切り落とし、平切りの幅は `apex_flat × 幹`。天なら高さはキャップ＋`overshoot.apex`、地なら −`overshoot.apex`。両端が頂点の斜画は `crotch_thin` 倍の一定幅。M の左右の天と、N の左上・右下はこれ。下向きの `apex`（会う高さが 0.5 未満。V と W の下）は外縁の交点、平切り、`apex_taper` の一様な先細り。天で会う `apex` で、その脚が地の頂点に使われていないものは、同じ作りを上下に反転する。足は基線で平切り、はみ出しは無い。谷は内縁の交点。天で会う `apex` でも、脚がすでに地の頂点になっているもの（W の中央）は、できた平らな天を同じ平切りと尖りのはみ出しに持ち上げる。A の横棒は `bar` にしない。`arm` の中心は骨格の y のまま（モダンは 0.22）。

### 開いた端

S C G の開いた端は `beak`。腕の端から字の内側へ垂らし、上端を腕の外縁にそろえる。J 2 3 5 6 9 の丸い端は `round_end`（シックは玉）。E F L T の開いた端は `open`。どのテンプレになるかは様式が決める。モダンの `open` は平切り。

### 数字

数字はライニング。0 と O、1 と I を見分けられる形にする。数字の幅はプロポーショナルで、字ごとに `proportions` の幅を持つ。タブラーの送りはそろえない（2026-11-03 作者が決定）。

### スラッシュ

`/` のグリフ名は `slash`、符号位置は U+002F。太さは斜画（mono の幹）と同じ。端は様式の端物。モダンは平切りで、基線からキャップまで。角度は暫定で約 60°。側面は `diagonal` / `diagonal`。

### シグネチャ

様式ごとに、目で見て分かる特徴を3つ以上、骨格に書く。何を特徴にするかは未決定。作者が組見本で決める。I L T E F には書かない。

### 幅

字の幅の係数は様式の `proportions` に置く。新しい字の値は暫定で、作者が組見本で決める。送り幅は墨の幅に側面を足したものなので、幹1本の I では `proportions` の値が墨の幅を変えない。墨の幅はペンの太さで決まる。
