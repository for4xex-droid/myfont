# 参照再現ループ

正本は書かない。

```
engine/.venv/bin/python scripts/reproduce_ref.py --mode exact --chars 十ニ三口日
```

`--mode exact` は参照グリフをサブセットして通す。fontmake / UPM 変換はしない（二次曲線の巻き戻しで形が動くため）。

2026-08-17 IPAex exact: 十ニ三口日の画素 IoU **1.000000**（xor 0）。`compare.png` の右列は差分（赤）。

`--mode invert` は骨格近似。平均 IoU 0.559。寸分違わぬには使わない。

要素抽出とテンプレ再構成:

```
engine/.venv/bin/python scripts/extract_ref_elements.py --chars 十二三口日
engine/.venv/bin/python scripts/rebuild_from_elements.py --chars 十二三口日
```

残差輪郭は捨て、ステム矩形＋うろこ比（bottom 0.91 / tip_y 0.20 / peak_x 0.43）で組み直す。軸画字のベクトル IoU は 0.98 台。1.0 にはならない（うろこの二次曲線を折れ線にした分）。

箱うろこ（口・日）は棒と別家族。はらいと端物の残差は二次を潰さない（折れ線化は分割・くびれの解析だけ。弧長96点だと人・入は 0.980 で頭打ち）。八・人・入は 1.000。入は屋根を頂点の X まで伸ばし、肩の直角三角形を載せる。穴がある字（又）は屋根にしない。くびれで切れない残差は左右輪郭のまま残す（文）。手の広い天は三角キャップにせず折れとして持つ。

開いた十字／開いた T はステムを伸ばして閉じる（箱うろこの小さい隙間は触らない）。融合残差は半幅 0.08em 超なら1本を拒否し、幅のくびれで切る。くびれ再構成が残差の左右輪郭より悪ければ切らない（心の下画）。役割 `other`（玉の点、心の点、少の払い）も左右輪郭で戻す。穴の上下辺が太い横画に見える矩形は、インク率 0.55 未満なら捨てる（国・東・車）。濾過は重複削除より先（言の細い横画が穴矩形に食われない）。開いた十字は最近傍の横画だけ、ギャップ 3.5h まで（国の中の玉を外枠に繋がない）。伸ばす区間のインク率が 0.55 未満なら閉じない（車の腰。田のマスはインクがあるので閉じる）。打ち込みは半矩形なので接合にせず、残差の三角を戻す（二・三が 1.000）。端物残差は左右輪郭で戻す。三角うろこは近似で、国・車・風の肩が足りなかった。木本・永は 0.98 前後。大天火水も 0.97 前後。

```
engine/.venv/bin/python scripts/catalog_ref_elements.py
```

軸画・箱穴・永字・斜画・字面を 13 字で測る。出力 `catalog.json` / `catalog.md` / `catalog.png`。
