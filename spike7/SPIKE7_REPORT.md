## A. 写像器（最小実装）

### 実装内容

1. **spike2 `flatten_glyph` 流用**で alias＋type99 再帰展開
2. **タイプ写像**: 1→H/V、2→次数上げ＋left/right/ten、3→2直線分割、6→cubic近似、7→left_hara、0→skip
3. **座標**: KAGE 200×200 Y下 → prototype SVG（Y下・UPM1000）へ **×5 のみ**（PLAN §0.1 の Y反転は製品移行時）
4. **フォールバック**: 警告ログ＋`FallbackKind` 集計。type2 の通常次数上げは警告対象外

### スパイクで発見した写像上の必須補完

- KAGE は **tag0（open）でも描画エンジンが黙定ディテールを付ける**が、prototype はタグ駆動のため、リテラル写像だけだと「十」「木」からうろこが消える
- 対策（スパイク規則）: **両端 tag=0 のときだけ** 横=`uchikomi+uroko`、縦=`uchikomi+tome` を補う（仕様ドラフトに明記）
- 短曲線→点の閾値は **スケール後 UPM 空間**で取る必要あり（初期バグを修正）

| 項目 | 判定 |
|---|---|
| ①行パーサ | spike2で実証済み。本スパイクは流用 |
| ②部品展開器 | spike2流用で100字・代表字とも欠落0 |

| 100字ゲート | **機械成功率100%は実証**。目視品位ゲートは「認識可だが接合前」であり、製品ゲートとしては **P2完了後に再実施が必要** |
| **工数40〜80h** | **妥当**。変換MVPは数日で通るが、写像仕様の角/接続/黙定・100字の目視分類・仕様書固定が残りコスト |

### KAGE骨格の品位問題（§3.4 層A〜D）

引用（PLAN §3.4）:
> 層A 一括幾何補正 / 層B 部品テンプレ / 層C 頻出300字手修正 / 層D 低頻度は許容

実物（肉付け後）を見た深刻度:

| 層 | 深刻度（本スパイク所見） | 根拠 |
|---|---|---|
| A 幾何補正 | **中** | 字面は概ね収まるが、囲みの内寄り・画間すき間は手を入れたい字あり |
| B 部品差し替え | **中〜高（印象）** | ごんべん・さんずい等は認識できるが、部品単位の品位が製品印象を左右（語・海） |
| C 頻出手修正 | **必要（ただし「読めない」ほどではない）** | 角のうろこ過大、点の形、接合前の見た目。認識不能ではない |
| D 低頻度許容 | **方針維持可** | 機械変換は落ちない。目立つものだけCへ |

**「骨格がひどくて字にならない」級の破綻は本サンプルでは観測されず。** 深刻なのは骨格単体より、**(1) 接合未実装 (2) 端点黙定/角写像 (3) classicパラメータが部品スケールに非適応** の組み合わせ。

## PLAN 修正点リスト

1. **§3.1 P4a**: 写像仕様に「KAGE tag0 黙定ディテールの再現規則」と「角（囲み右上）の専用規則」を DoD に含める
2. **§0.1 / P4a**: スパイク段階では prototype 互換のため Y下×5を許容し、**製品骨格JSON凍結時に Y上反転を必須ゲート**と明記（二段階）
3. **§3.4**: 「KAGE品位不足」の判定を、骨格折れ線単体ではなく **肉付け＋（可能なら）接合後の目視**で行うと追記。本スパイクでは認識品質は十分、製品印象は P2+P4b 依存
4. **§3.1 P3 と P4a の依存**: P4a の100字品質ゲートを「接合前ゲート（認識・写像）」と「接合後ゲート（製品）」に分割。前者は本スパイク相当で早期実施可
5. **§3.8 撤退基準「P4aの100字品質ゲート不合格」**: 不合格定義を数値化（例: 認識不能>5%、ハードFB>10%、角飛び出し重大>20字 等）。現状の「認識可」だけでは不合格にならない
6. spike2 修正点の継続: 部品展開器を P4a 本体と明記（v5で概ね反映済み。本スパイクで接続まで実証）
